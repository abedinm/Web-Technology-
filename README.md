## Running locally with XAMPP

This folder is symlinked into the XAMPP web root, so Apache serves every lab:

1. Start **Apache** from the XAMPP manager (`/Applications/XAMPP/manager-osx.app`).
2. Open a task in the browser, e.g. http://localhost/Web-Technology-/lab-01-registration-form/
